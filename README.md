# Bohu Wedding

Elegant React wedding & wedding planner website inspired by modern romantic templates like Bohu.

## Features

- Planner homepage with full-bleed hero, services, portfolio, testimonials, team, journal
- Couple invitation page with countdown, story, schedule, gallery, RSVP CTA
- About, Services, Portfolio, Journal, Contact, and RSVP pages
- Sticky responsive header, form validation (HTML), mobile menu
- Original romantic design (blush / sage / ink) — not a copy of paid ThemeForest assets

## Run

```bash
cd bohu-wedding
npm install
npm run dev
```

Open the local URL Vite prints (usually http://localhost:5173).
